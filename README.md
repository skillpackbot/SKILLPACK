## What is SKILLPACK?

SKILLPACK is a collection of ready-to-install skills designed for [Bankr](https://bankr.bot) agents operating on **Base** and **Robinhood Chain**.

These skills help agents:
- Bridge tokens between Base ↔ Robinhood Chain
- Fair-launch tokens and earn creator fees
- Trade tokenized stocks
- Run automation (DCA, TWAP, limit, stop-loss)
- Stay self-funding through trading fees

## Skills Overview

| Skill | Description |
|-------|-------------|
| **skillpack-bridge** | Bridge tokens Base ↔ Robinhood via LayerZero OFT + seed liquidity |
| **skillpack-launch** | Fair-launch tokens on Base or Robinhood with fee sharing |
| **skillpack-fee** | Track, claim & report creator fees |
| **skillpack-stock** | Trade tokenized stocks (NVDA, AAPL, META, etc.) |
| **skillpack-arb** | Find & act on price differences between Base and Robinhood |
| **skillpack-agent** | Full self-sustaining agent workflow (launch → fees → compute) |
| **skillpack-alpha** | Research & alpha scanner for new tokens and stock tokens |
| **skillpack-auto** | DCA, TWAP, limit orders, stop-loss |
| **skillpack-portfolio** | Multi-chain portfolio + PnL tracker |
| **skillpack-x402** | x402 payment helpers for paid features & tips |
